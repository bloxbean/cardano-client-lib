Built for real applications

The hard parts are already handled

Complete transaction support

Payments, multi-asset outputs, native-script and Plutus minting, reference scripts and inputs, staking certificates, and every Conway governance action.

Any backend

Blockfrost, Koios, Ogmios and Kupo, Nexus, or your own. Swap providers by changing one constructor.

Type-safe on-chain data

Generate Java classes from a CIP-57 blueprint, with compile-time-checked datums and redeemers.

Programmable tokens

Register, mint, transfer, seize and burn CIP-113 tokens whose rules live in your own validators, with the protocol's plumbing handled for you.

Verified data structures

Keep data off chain and prove it on chain, with Merkle Patricia Forestry proofs for Aiken validators, or Jellyfish Merkle Trees for versioned state.

Agent friendly

A published llms.txt and a machine-readable module catalog, regenerated on every build.
Start simple, scale later

When one transaction isn't enough

A follow-up transaction can spend an output that's still pending, with no race against the chain. And a transaction that goes missing is reported as uncertain, never as a false success.
